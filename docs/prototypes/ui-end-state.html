The counter needs to handle Windows line endings. I'll read line-by-line via BufRead::lines() which strips terminators, and use a simple loop with a counter. For the --non-empty flag, I'll check !line.trim().is_empty().
Tool call · write · src/lib.rs 
use std::io::BufRead;

/// Count lines from any BufRead, optionally skipping blanks.
pub fn count_lines<R: BufRead>(reader: R, non_empty_only: bool) -> usize {
    reader
        .lines()
        .filter_map(|l| l.ok())
        .filter(|l| !non_empty_only || !l.trim().is_empty())
        .count()
}
